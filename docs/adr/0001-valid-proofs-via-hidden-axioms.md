# Valid proofs via explicit hidden axioms

The book often jumps from weak premises to strong conclusions ("some people with the same past act differently" → "trauma does not exist"). We require every Theorem to be valid, so we keep the book's conclusion and surface the unstated assumption as an explicit Axiom marked "hidden in book". The alternative was to weaken each conclusion to what the stated premises prove. We rejected it because that hollows out Adler's actual claims. Making the hidden axiom explicit shows exactly what a reader must accept, and which conclusions fall if they reject it.
